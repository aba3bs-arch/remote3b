Inicia sesion para ver las computadoras de tus tiendas.

      Acceso atendido

      Usa Always-ON para las tiendas: el agente queda instalado y puedes entrar aunque no haya nadie frente a la PC. El acceso atendido es para una sesion puntual, cuando alguien en la tienda puede confirmar.

      Para tiendas 3B, deja el agente instalado con inicio automatico de Windows.

      Configura esta computadora para acceso remoto Always-ON

      Iniciar sesion

      Crea una cuenta gratis o entra para ver las PCs de tus tiendas. No hay suscripcion.

      La contrasena debe tener 12+ caracteres, mayuscula, minuscula, numero y simbolo.

      Opciones avanzadas

      Agregar computadora de tienda

      Ponle el nombre de la sucursal, por ejemplo 3B7 Del Valle. Luego corre el instalador en esa PC.

      Como conectar tus tiendas sin pagar

      1. Crea tu usuario e inicia sesion en este panel.
      2. Pulsa Agregar computadora y nombra la sucursal.
      3. En la PC de la tienda, abre PowerShell y pega el comando. Eso instala el agente Always-ON.
      4. Cuando el icono se ponga verde, haz doble clic para ver y controlar la pantalla.

      El agente solo debe instalarse en equipos de 3B o con permiso explicito del dueno.
